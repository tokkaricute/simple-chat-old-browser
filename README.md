# Simple Chat for Old Browser

「Simple Chat for Old Browser」は、Microsoft Edge (Version 20H2) などの比較的古いブラウザ環境でも安定して動作するように設計された、軽量なチャットウェブアプリケーションです。

OllamaやLM StudioなどのOpenAI互換APIと連携し、ローカルまたはリモートのLLMとシームレスに対話できます。

## 特徴
- **高い互換性**: モダンなフレームワークを使わず、Vanilla JSと標準CSSのみで構築されているため、古いブラウザでも崩れにくく、高速に動作します。
- **ストリーミング対応**: LLMの回答をリアルタイムで逐次表示します。
- **セッション管理**: チャット履歴はSQLiteに自動保存され、後からいつでも再開可能です。
- **直感的な操作**: セッション未選択状態でのメッセージ入力時には、自動的に新しいセッションが作成されます。
- **簡単設定**: `config.yaml` を編集するだけで、接続先URLやシステムプロンプトを即座に変更できます。

## 動作要件
- **Python**: 3.12 以上
- **パッケージ管理**: [uv](https://github.com/astral-sh/uv)
- **ブラウザ**: Microsoft Edge 20H2 以上推奨

## インストールと起動方法

### 1. リポジトリの準備
プロジェクトディレクトリに移動します。
```bash
cd simple_chat_old_browser
```

### 2. 環境構築
`uv` を使用して依存関係をインストールします。
```bash
uv sync
```

### 3. 設定の確認
`config.yaml` を開き、接続先のAPI URLなどが正しいか確認します。
```yaml
api_url: "http://localhost:1234/v1"  # OllamaやLM StudioのURL
port: 8875
...
```

### 4. アプリケーションの起動
以下のコマンドでサーバーを起動します。
```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8875
```

起動後、ブラウザで `http://localhost:8875` にアクセスしてください。

## 利用方法
- **チャットを開始する**: メッセージを入力して「送信」ボタンをクリックします。（セッションを選択していない場合は自動作成されます）
- **新しいチャットを作る**: サイドバーの「+ New Chat」をクリックします。
- **設定を変更する**: 画面上部の入力欄で「システムプロンプト」を書き換えることができます。
- **履歴を消す**: セッション一覧の「×」ボタン、または現在のチャット内容を消去する「消去」ボタンを使用します。
