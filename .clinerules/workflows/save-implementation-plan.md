- Document管理は以下の通りとする。
    1. `implementation_plan.md`を`docs/prompt`へ格納する。
        - ファイル名はimplementation_plan_yyyyMMddHHmmss.mdとする
    2. `implementation_plan.md`の内容からArchitecture Decision Record(ADR)を作成し、`docs/adr`へ保存する。
        - ADRの形式はMichael Nygardに準拠
    3. `implementation_plan.md`の内容からDesign Docを作成し、`docs/design`へ保存・更新する。
        - Design Docの形式はGoogle Design Docsに準拠
    4. `implementation_plan.md`を削除する。
